# Measurement and Iteration

Closing the loop: did the feature actually do what the PRD said it would, stated plainly - met, missed, or not yet measurable. This is also where the cycle re-enters: what's learned here is exactly the kind of evidence [`discovery-and-opportunity-sizing`](../discovery-and-opportunity-sizing) looks for when sizing the next problem, which is why product management is a loop rather than a straight line from inception to launch.

**Comes after:** [`launch-and-growth`](../launch-and-growth), once the feature has been live long enough to measure. **Feeds back into:** [`discovery-and-opportunity-sizing`](../discovery-and-opportunity-sizing) for the next cycle.
