# Discovery and Opportunity Sizing

Where product work starts: is this problem real, who has it, and is it worth solving before any solution gets proposed. This is the stage before a PRD exists - evidence-gathering and market/competitive grounding, not spec-writing.

**Feeds into:** [`strategy-and-prioritization`](../strategy-and-prioritization) once a problem is sized and worth acting on.

## Contents

| Item | Type | What it does |
|---|---|---|
| [`opportunity-assessment-agent`](agents/opportunity-assessment-agent) | Agent (spec) | Pulls real support/CRM evidence for a candidate problem and produces a sized Opportunity Brief before it becomes a PRD |
| [`competitive-teardown-agent`](agents/competitive-teardown-agent) | Agent (spec) | Searches and fetches competitors' current public pages to verify - not assume - how they solve a given problem |
